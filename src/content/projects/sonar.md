## Overview

Project S.O.N.A.R. is a privacy-focused audio marketplace built on Sui infrastructure. I am its sole creator.

## How It Works

Sellers upload audio files stored on Walrus. Every file is quality-verified. Seal access control gates each file so buyers receive secure access after purchase. Nautilus provides verifiable compute over the marketplace flow.

## Win Context

Project S.O.N.A.R. won Best Technical Implementation at the Walrus Haulout Hackathon 2025. Judges selected it from hundreds of submissions across 27 countries as one of three technical-implementation winners.
